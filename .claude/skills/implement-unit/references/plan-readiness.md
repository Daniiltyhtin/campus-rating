# Готов ли юнит к реализации

Ответь на каждый вопрос «да» со ссылкой на место в плане. Любое «нет» — вопрос человеку до кода.

1. Понятно, что наблюдаемо изменится для пользователя или системы (Goal + R)?
2. Для каждого условного поведения («если X, то Y») есть пример с числами или явное правило (AE или R)?
3. Известны границы: пустые входы, максимум, повтор, гонка, права?
4. Понятно, какие файлы трогать и какие — нет (`Files`, Scope Boundaries)?
5. Есть тест-сценарии с конкретными входами и ожиданиями?
6. Понятно, как доказать готовность (Verification юнита и Verification Contract)?
7. Нет противоречий между юнитом, его R/KTD и глоссарием?

Слепая проверка: представь исполнителя, который видит только юнит и его ссылки. Какое решение ему придётся угадать? Если такое есть — это вопрос, а не твоя догадка.
