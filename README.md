# Campus Rating

MVP университетской социальной сети: академический рейтинг, баллы учебной и общественной активности, ленты наград и событий. Проект хакатона 2026, разрабатывается командой вместе с ИИ-агентами.

Спецификация — [docs/spec/](docs/spec/README.md). Новому участнику — [онбординг](docs/onboarding.md).

Из корня клона, с установленным Docker и Compose v2:

```bash
docker compose up
```

Образы собираются автоматически; `.env` не нужен. После готовности сервисов откройте [http://localhost:8080](http://localhost:8080) — сейчас там статичная заглушка входа. Демо-аккаунты появятся в мастер-U5.

Локальный стенд работает в режиме `demo`: база пересоздаётся при каждом старте backend, изменения данных удаляются. Подтверждение email явно выключено (`EMAIL_VERIFICATION=off`); SMTP и Mailpit для запуска не нужны. Демо-сид добавит мастер-U4, очистку файлов загрузок — мастер-U7.

Все опубликованные порты доступны только на `127.0.0.1`:

| Сервис | Адрес | Назначение |
|---|---|---|
| web | `http://localhost:8080` | SPA и прокси `/api/` на backend |
| backend | `http://localhost:8081` | API для разработки; Vite проксирует сюда `/api` |
| PostgreSQL | `localhost:5433` | Подключение локальных инструментов к БД |

Для разработки frontend: `npm --prefix frontend ci`, затем `npm --prefix frontend run dev`. Локальный Vite использует backend запущенного стека. Необязательные параметры БД описаны в `.env.example`.

Запуск с ожиданием готовности и остановка:

```bash
docker compose up -d --build --wait
docker compose down
```

`docker compose down` сохраняет тома; `docker compose down -v` удаляет БД и загруженные файлы. Перезапуск backend в режиме `demo` пересоздаёт схему и при сохранённом томе.
