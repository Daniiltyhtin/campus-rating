# Журнал работы с агентами

Что команда поручала агентам, где они ошибались, как это обнаружили и исправили, что сработало. Новая запись — в конец, скиллом `agent-log`; прошлые записи не переписываются. Уроки отсюда переносятся в раздел «Уроки» `AGENTS.md` только после слияния своей ветки.

## Шаблон записи

```markdown
### ГГГГ-ММ-ДД — <юнит или тема>

- **Кто / агент / модель:** <человек> / <Claude Code | Codex> / <модель>
- **Поручение:** <что поручили, ссылка на план или юнит>
- **Результат с доказательствами:** <команды и итоги, ссылки>
- **Не проверено:** <что и почему>
- **Неудачные попытки:** <что пробовали и почему отказались>
- **Ошибка агента:** что случилось → как заметили → как исправили
- **Урок:** что случилось → как заметили → как теперь делать (пути файлов)
- **Кругов ревью:** <N>
- **Коммит / PR:** <ссылка>
```
