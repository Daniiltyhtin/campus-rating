# Презентация защиты

20 слайдов на 15 минут вместе с демо, стиль «Ведомость» — шрифты и цвета продукта ([ADR009](../../spec/architecture-decisions/adr009-visual-style.md)). Раскрывает восемь пунктов выступления из ТЗ: цель, роли, архитектура, интерфейс, тестирование, работа с агентами, внедрение в вуз, развитие.

| Файл | Что это |
|---|---|
| `campus-rating.pptx` | для показа и отправки; шрифты встроены, в заметках слайдов — кто говорит и сколько секунд |
| `campus-rating.html` | та же презентация в браузере; один файл, шрифты грузятся с Google Fonts |
| `src/content.py` | текст слайдов и заметки выступающего — править здесь |
| `src/build.py` | сборка HTML и PPTX, проверка, что текст не выходит за свои рамки |
| `assets/` | скриншоты продукта из `docs/reviews/` и прототипа нового дизайна «Блоки» |

## Показ

- **PPTX** — PowerPoint, режим докладчика показывает заметки.
- **HTML** — открыть файл в браузере (не в просмотре мессенджера). Стрелки, пробел, PageUp/PageDown, свайп; `#s11` в адресе — сразу слайд демо. Клавиша `E` — правка текста на слайде, `Ctrl+S` сохраняет HTML с правками.

## Пересборка

Нужны Python 3, `pip install pillow python-pptx playwright` и `playwright install chromium`.

```bash
cd docs/presentation/deck/src
python build.py
```

Скрипт перезаписывает `campus-rating.html` и `campus-rating.pptx` и печатает `OVERFLOW 0`, если ни один текст не вылез за рамку; скриншоты слайдов кладёт во временную папку ОС.

Шрифты в PPTX сборка не встраивает: поставьте Literata, PT Sans и PT Mono с Google Fonts, откройте файл в PowerPoint, включите «Файл → Параметры → Сохранение → Внедрить шрифты в файл» и сохраните.
