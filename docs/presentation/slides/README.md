# Презентация защиты

21 слайд на 14 минут вместе с живым демо. Раскрывает восемь пунктов выступления из ТЗ хакатона, плюс слайды «Что сделано из ТЗ» и «Безопасность».

| Файл | Что это |
|---|---|
| `frontend/public/presentation/index.html` | сама презентация; уезжает на стенд обычной сборкой web-образа и открывается по `/presentation` без входа |
| `frontend/public/presentation/demo.js` | живое демо: сайт стенда в рамке телефона, шаги нажимает презентация |
| `sources.md` | откуда каждая цифра на слайдах и как её получить заново |
| `checklist.md` | что проверить перед показом |
| `campus-rating.pdf` | PDF всех слайдов; на демо-слайдах вместо сайта — надпись |
| `export-pdf.mjs` | сборка PDF |

## Показ

- Стенд: `https://campus-rating.ru/presentation`, или ссылка «Презентация проекта» на странице входа.
- Локально: `docker compose up -d --build --wait`, затем `/presentation` на адресе web-сервиса.
- Листать: стрелки, пробел, PageUp/PageDown; `#s12` в адресе — сразу слайд 12. `N` — заметки выступающего, `E` — правка текста на слайде (правки живут до перезагрузки и на стенд не попадают; постоянные правки — в `index.html`).
- Демо: на слайде «Живое демо» ввести префикс демо-паролей стенда. Он хранится только в памяти вкладки. Шаги запускаются кнопкой «Запустить шаг» по порядку. Если стенд не ответил за 15 секунд — пролистать шаги и продолжить с раздела «Интеграция в жизнь вуза».

## PDF

Нужен Playwright из `e2e/node_modules`:

```bash
node docs/presentation/slides/export-pdf.mjs
```

Скрипт открывает `index.html` с параметром `?export`, снимает каждый слайд 1920×1080 и собирает `campus-rating.pdf`.

## Правка цифр

Новый срез — новые цифры: пройти `sources.md` сверху вниз, обновить значения на слайдах и в таблице. `node --test tools/test/presentation.test.mjs` проверяет, что у каждой цифры есть строка источника, в колонке не больше пяти пунктов и сумма времени в заметках не больше 840 секунд.
