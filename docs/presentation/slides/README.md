# Презентация защиты

21 слайд на 14 минут вместе с живым демо. Раскрывает восемь пунктов выступления из ТЗ хакатона, плюс слайды «Что сделано из ТЗ» и «Безопасность».

| Файл | Что это |
|---|---|
| `frontend/public/presentation/index.html` | сама презентация; уезжает на стенд обычной сборкой web-образа и открывается по `/presentation` без входа |
| `frontend/public/presentation/demo.js` | демо: проигрывает записи шагов; с `?live` — живой режим, шаги нажимает сама презентация |
| `frontend/public/presentation/demo/` | записи шагов (mp4) и их первый и последний кадры |
| `record-demo.mjs` | перезапись роликов |
| `sources.md` | откуда каждая цифра на слайдах и как её получить заново |
| `checklist.md` | что проверить перед показом |
| `campus-rating.pdf` | PDF всех слайдов; на демо-слайдах вместо сайта — надпись |
| `export-pdf.mjs` | сборка PDF |

## Показ

- Стенд: `https://campus-rating.ru/presentation`, или ссылка «Презентация проекта» на странице входа.
- Локально: `docker compose up -d --build --wait`, затем `/presentation` на адресе web-сервиса.
- Листать: стрелки, пробел, PageUp/PageDown; `#s12` в адресе — сразу слайд 12. `N` — заметки выступающего, `E` — правка текста на слайде (правки живут до перезагрузки и на стенд не попадают; постоянные правки — в `index.html`).
- Демо — запись прохода по стенду в рамке телефона: на слайде шага клавиша → (или пробел) запускает запись шага, следующее нажатие листает дальше. Сеть, пароли и бюджет на показе не нужны.
- Живой режим — `/presentation?live`: та же рамка, но шаги выполняются на стенде по-настоящему. Нужен префикс демо-паролей (поле на слайде «Демо», хранится только в памяти вкладки); каждый прогон тратит 38 баллов бюджета ИВТ-21 у Петрова.

## Перезапись демо

Нужны ffmpeg, Playwright из `e2e/node_modules` и свежий локальный стек — у Петрова должен быть бюджет ИВТ-21 на один прогон:

```bash
docker compose up -d --build --wait
docker compose up -d --force-recreate --wait backend
node docs/presentation/slides/record-demo.mjs
```

Скрипт проходит семь шагов в живом режиме, вырезает рамку телефона и сохраняет ролики в `frontend/public/presentation/demo/`; ожидание дедлайна в запись не попадает.

## PDF

Нужен Playwright из `e2e/node_modules`:

```bash
node docs/presentation/slides/export-pdf.mjs
```

Скрипт открывает презентацию с параметром `?export` (на демо-слайдах — последний кадр записи), снимает каждый слайд 1920×1080 и собирает `campus-rating.pdf`.

## Правка цифр

Новый срез — новые цифры: пройти `sources.md` сверху вниз, обновить значения на слайдах и в таблице. `node --test tools/test/presentation.test.mjs` проверяет, что у каждой цифры есть строка источника, в колонке не больше пяти пунктов и сумма времени в заметках не больше 840 секунд.
