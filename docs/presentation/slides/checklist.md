# Перед показом

- [ ] Остаток бюджета ИВТ-21 у Петрова — не меньше 38 баллов: каждый прогон демо расходует 38. Если меньше — сбросить стенд к сиду по `deploy/README.md`, раздел «Сброс к демо-данным».
- [ ] `https://campus-rating.ru/presentation` открывается, на слайде «Живое демо» введён префикс демо-паролей стенда.
- [ ] Шаг 1 демо запускается не раньше чем через 60 секунд после предыдущего прогона: перед выступлением не жать его в последнюю минуту. Не запускать демо одновременно из двух вкладок или с двух ноутбуков: точки и активности одной минуты получат одинаковые названия.
- [ ] Заметки выступающего — клавиша `N`; таймер выступления — 15 минут на всё.
- [ ] Если стенд не ответил — пролистать шаги демо и продолжить с раздела «Интеграция в жизнь вуза».
