# Перед показом

- [ ] `https://campus-rating.ru/presentation` открывается; на слайде шага 1 по клавише → проигрывается запись.
- [ ] Заметки выступающего — клавиша `N`; таймер выступления — 15 минут на всё.
- [ ] Если просят показать вживую — `/presentation?live`, префикс демо-паролей стенда. Каждый живой прогон тратит 38 баллов бюджета ИВТ-21 у Петрова; если остаток меньше 38 — сброс стенда к сиду по `deploy/README.md`, раздел «Сброс к демо-данным». Не запускать живое демо одновременно из двух вкладок.
