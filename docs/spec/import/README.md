# Примеры импорта U13

Сначала создайте факультет с кодом `ФИТ` и кафедру с кодом `ПИ` в «Справочниках».
Затем импортируйте группы, студентов и список преподавателей соответствующими видами
на экране «Импорт». Все адреса примеров синтетические.

CSV — UTF-8 (с BOM или без) либо Windows-1251, разделитель запятая либо точка с запятой.
XLSX — первый лист с теми же заголовками. Значения в кавычках CSV могут содержать
разделители, кавычки и переносы строк. Пределы — 5 МБ и 5000 непустых записей данных.
Повтор тех же данных пропускается; ошибки показываются по строкам.

При настроенном SMTP импортированному студенту приходит ссылка установки пароля
на 24 часа. Без SMTP выставьте ему временный пароль в «Пользователях». Временный
пароль инвалидирует неиспользованные ссылки установки пароля.
