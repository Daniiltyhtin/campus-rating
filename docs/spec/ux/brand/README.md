# Знак Campus Rating «Орбита»

R и C по общему центру: голова R и дуга C — концентрические окружности, оба конца C срезаны одной прямой, параллельной ноге R. Превью в трёх темах и размерах 16–128 px — [`preview.html`](preview.html).

## Файлы

| Файл | Назначение |
|---|---|
| `frontend/src/assets/brand/logo-mark.svg` | знак для шапки и экранов; цвет — `currentColor`, тема меняет его без отдельного файла |
| `frontend/src/assets/brand/loader.svg` | загрузка, полный цикл 3,6 с: R втягивает ноги, голова скругляется в планету, вокруг проходит C; для заставки и долгой загрузки |
| `frontend/src/assets/brand/loader-wait.svg` | ожидание, оборот C за 1,2 с; для коротких ожиданий в кнопках и блоках |
| `frontend/public/favicon.svg` | фавикон: `#161b22`, в тёмной теме браузера — `#e6edf3` |
| `frontend/public/favicon-32.png`, `favicon-16.png` | фавикон для браузеров без SVG |
| `frontend/public/apple-touch-icon.png` | иконка 180 × 180 на фоне `bg` светлой темы |

## Правила

- Цвет знака — только токены темы: `text` (основной) или `primary`; знак наследует `color` родителя.
- Минимальный размер — 16 px. В шапке — 24–32 px рядом с надписью «Campus Rating» шрифтом Literata 700.
- Знак не вращают, не обводят, не кладут на градиенты и фото; анимация — только в файлах загрузки.
- Анимации загрузки — SMIL внутри SVG; при `prefers-reduced-motion: reduce` вместо них показывается статичный `logo-mark.svg`.

Подключение в шапку и вместо скелетонов загрузки — в плане правок UI после проверки U7.
