# UX-карта: экраны, навигация, ключевые пути (U21a)

Структура интерфейса до визуального стиля. Каркасы серые намеренно: здесь решаются состав экранов, иерархия и состояния; цвета, шрифты и закругления — в U21b, тема и шаблоны страниц — в U21c. Требования — из мастер-плана (`R`), термины — из `glossary.md`. Решения команды по открытым вопросам — в `open-questions.md`.

Каркасы: полотно с исходниками в `wireframes/` (формат Design Component, рендерится на полотне дизайна; ссылка у владельца репозитория). Студент — 360 px, преподаватель — 1280 px и 360 px.

## Навигация

- Десктоп — боковая панель, мобильный — нижняя, не больше пяти пунктов. Пункты зависят от роли.
- У всех ролей в шапке аватар: меню «Мой профиль», «Уведомления» (только если сделан U18), «Выйти».
- Профиль любого пользователя открыт всем вошедшим (R5): имя в ленте, рейтинге и таблице точки — ссылка на профиль.

| Роль | Пункты |
|---|---|
| Студент | Главная · Задачи · Активности · Награды · Профиль |
| Преподаватель | Главная · Точки · Активности · Группы · Профиль |
| Администратор | Справочники · Импорт · Семестры · Настройки · Старосты |

«Главная» — персональная лента событий (U14, P1). До U14 — сводка: баллы и ближайшие дедлайны у студента, работы на проверке у преподавателя.

Вторичные разделы без своего пункта открываются из контекста:

| Раздел | Где вход |

| Опросы | «Главная»: блок «Новые опросы» у студента, «Мои опросы» у преподавателя |

## Ключевые пути

1. **Регистрация студента** (R1, R8, R31, R32): регистрация → факультет сужает группы → (P2) письмо, вход закрыт до подтверждения → профиль с АР 1000 и строкой «Стартовые баллы». (P2) Пока членство `PENDING`: на «Главной» и в «Задачах» — «Членство в ИВТ-21 ждёт подтверждения старосты или преподавателя»; после активации — задачи по точкам с будущим дедлайном.
2. **Сдача просроченной работы** (R10–R12, R15): задачи → задача «Просрочено, списано 40 из 60, следующее −20 через 0:42» → ссылка или файл ≤ 10 МБ → «Сдано на проверку», штраф остановлен. Ошибка: файл не того типа — сообщение у поля, штраф идёт.
3. **Проверка работ** (R14): точка → фильтр «Сдано» → открыть сдачу из строки (ссылка или файл с именем; фильтр и выбор сохраняются) → выбрать несколько → «Принять 3 работы» → итог «Принято 2 из 3», у пропущенных — причина. Или «Вернуть…» с комментарием: до дедлайна студент видит «В процессе», после — «Просрочено» и предупреждение «штраф возобновится». Статус и комментарий видны студенту в задаче без персональной ленты.
4. **Активность** (R17–R20, R23): создать → студент видит максимум и время начала, записывается до начала (общественная) → после начала подтверждение с уровнями → при нехватке бюджета показан остаток по каждой группе, ничего не начислено → успех «Начислено 125 БОА», подтверждённые только для просмотра → награда в ленте и в истории.
5. **Рейтинг группы** (R22, R5): группы → рейтинг с сортировкой → профиль студента. Группа вне доступных по прямой ссылке — «нет доступа».

## UX-правила для всех экранов

- Каждый экран имеет состояния загрузки (скелетон), пустое (с объяснением, что появится и когда) и ошибки (с повтором).
- Штраф виден заранее: сколько списано, сколько ещё может быть списано и когда следующее списание. Блок штрафа в задаче — одно из пяти состояний; сумма следующего списания считается по R11 (не больше шага, остатка стоимости и АР):
  - до дедлайна — «До дедлайна штрафа нет; после — до −20 АР за каждый интервал»;
  - идёт — «Следующее списание −20 АР через 0:42»;
  - потолок достигнут — «Списано 60 из 60, больше не спишется»;
  - АР 0 — «Рейтинг 0: списание возобновится после пополнения» (AE4);
  - сдано или принято — «Штраф остановлен, списано 40».
- Необратимые действия называют итог в кнопке: «Принять 3 работы», «Начислить 125 БОА», а не «ОК». После массового действия — итог с числом и причинами пропусков.
- Ошибка бюджета показывает по каждой группе: нужно, остаток, не хватает (R20).
- Статусы задачи — только четыре из R15; цвет не единственный признак статуса (текст и форма рамки).
- Время показывается по Москве с датой и временем: дедлайны, начало активностей.
- Области нажатия на мобильном — от 44 px, включая вкладки, уровни участия и сортировку; навигация и вкладки — реальные ссылки и кнопки с доступными именами.
- Клавиатура: вкладки и радиогруппы переключаются стрелками, фокус всегда виден, после закрытия диалога фокус возвращается на кнопку, которая его открыла.
- Новые записи в ленте не сдвигают читаемую позицию: плашка «Новые награды: N — показать».
