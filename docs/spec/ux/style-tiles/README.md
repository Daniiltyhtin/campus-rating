# Варианты стиля (U21b)

Два варианта визуального стиля на одних и тех же фрагментах экранов из каркасов U21a: задача студента (С3), мои задачи и состояния (С2), профиль (С1), лента наград (С5), подтверждение участия (П2), точка преподавателя (П1, десктоп), элементы управления и токены. Разметка фрагментов одна, у вариантов разные только токены и несколько правил оформления.

Открыть: `docs/spec/ux/style-tiles/index.html` в браузере. Шрифты грузятся из Google Fonts, без сети страница показывается системным шрифтом. Переключатель вверху: «Рядом», «Только A», «Только B». На 360 px фрагменты показываются в натуральную ширину. Кнопки «Сдать работу» и «Начислить 125 БОА» показывают уведомление, чтобы было видно анимацию.

Команда выбирает вариант в чате. Выбор фиксирует ADR009, тему Mantine из выбранного варианта собирает U21c.

## Чем отличаются

| | A «Кафедра» | B «Кампус» |
|---|---|---|
| Характер | строгий, плотный, «рабочий инструмент» | тёплый, мягкий, «приложение кампуса» |
| Шрифт текста | Golos Text 400/600 | Onest 400/600 |
| Заголовки и баллы | Golos Text 600, цифры `tabular-nums` | Unbounded 600 |
| Основной цвет | синий `#2450c4` | фиолетовый `#5b3cc4` |
| Фон | холодный серый `#f5f6f8` | тёплый `#f6f3ee` |
| Радиус | 4 / 6 / 8 px, бейджи прямоугольные | 8 / 12 / 18 px, бейджи и чипы — пилюли |
| Отделение карточек | рамка 1 px, без теней | мягкая тень, без рамки |
| Акценты | цветная кромка: блок штрафа, баланс, активный пункт меню | тонированные карточки баланса, градиент блока штрафа, тень основной кнопки |
| Анимация | 120 мс `ease-out`, только цвет и прозрачность | 220 мс с лёгким перелётом, нажатие 0.97, подъём карточки, счёт баллов |
| Скелетон | пульсация | мерцание |

Общее в обоих: статусы назначения и валюты различаются цветом одинаково по смыслу, но всегда с текстом (статус не передаётся только цветом); кнопки и поля 44 px, основная кнопка внизу экрана 48 px; строки таблицы 52 px; анимации выключаются при `prefers-reduced-motion`.

## Как это ляжет в Mantine (U21c)

- `fontFamily`, `headings.fontFamily` — из строки «Шрифт»; шрифты ставятся пакетами `@fontsource/golos-text` или `@fontsource/onest` и `@fontsource/unbounded` (подмножество `cyrillic`), без запросов к Google Fonts в рантайме.
- `primaryColor` — своя шкала из 10 оттенков, где оттенок 6 (`primaryShade: 6`) — `primary`, 7 — `primary-hover`, 0 — `primary-soft`.
- `defaultRadius` — средний радиус варианта (6 или 12 px); радиусы `xs…xl` — из строки «Радиус».
- `shadows` — пусто для A, две тени B (`sm` для карточек, `md` для всплывающих).
- Цвета статусов и валют — не цвета Mantine, а CSS-переменные темы (`other` или `cssVariablesResolver`) с именами из глоссария: `--cr-status-overdue`, `--cr-currency-ar` и так далее; литералы цветов в `features/` запрещает правило U21c.
- Длительность и кривая анимации — переменные темы; `Button` получает `:active { transform: scale(...) }` только в B.
