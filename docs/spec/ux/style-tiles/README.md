# Визуальный стиль (U21b)

Выбранный стиль — «Редакция» в цветах «Кафедры». Решение и причины — [ADR009](../../architecture-decisions/adr009-visual-style.md). Тему Mantine, шаблоны страниц и `/styleguide` из него собирает U21c.

Посмотреть: `final/index.html` в браузере. Там лист стиля с палитрами и компонентами, задача (С3), профиль (С1) и точка преподавателя (П1), каждый экран в трёх темах. Страница статическая, сеть нужна только для шрифтов.

## Правила стиля

- **Полоса, а не карточки.** Блоки разделяют тонкие линейки; сверху экрана и над балансом — линейка цвета текста. Теней нет, карточки-коробки не используются.
- **Шрифты.** Literata — заголовки и крупные числа (баллы, «40 из 60 АР»), `lining-nums tabular-nums`. PT Sans — всё остальное. Оба с кириллицей.
- **Цвет только со смыслом.** Синий — действия, ссылки, активный пункт. Цвета статусов и валют — только у статусов и сумм. Остальное — оттенки серого.
- **Без прописных.** Подписи, рубрики и шапки таблиц — обычным регистром. Исключение — аббревиатуры АР, БУА, БОА.
- **Статус назначения** — мягкая пилюля: обычный регистр, без жирного, скругление 999 px, фон и текст цвета статуса.
- **Итог действия** («Принято 2 из 3. …») — без фона: цвета успеха только галочка и первые слова, остальное — цветом текста.
- **Панель массового действия** — серый фон `surface-2`, цвет только у основной кнопки.
- **Выбранная строка таблицы** — без заливки: отмеченный чекбокс и линия под строкой 2 px (в высоком контрасте — 3 px, чёрная).
- **Вкладки и фильтры** — подчёркивание 3 px основным цветом у активной, остальные — вторичным текстом.
- **Комментарий возврата** — цитата Literata курсивом на сером фоне.

## Перенос в Mantine 9 (U21c)

- `fontFamily: 'PT Sans, system-ui, sans-serif'`, `headings.fontFamily: 'Literata, Georgia, serif'`; шрифты пакетами `@fontsource/pt-sans` (400, 700) и `@fontsource/literata` (500–700), подмножество `cyrillic`, без Google Fonts в рантайме.
- `primaryColor` — своя шкала из 10 оттенков вокруг `primary` светлой темы (например, генератором `@mantine/colors-generator`), оттенок для кнопок — `primary`; для тёмной темы — `primaryShade: { light: 6, dark: 4 }` или явный `virtualColor`.
- `defaultRadius: 6px` для кнопок и полей; пилюли — `radius: xl`; таблицы и блоки без радиуса.
- `shadows` — пустые: глубину дают линейки.
- Токены из таблицы — CSS-переменные темы через `cssVariablesResolver` (`--cr-bg`, `--cr-status-overdue`, `--cr-currency-ar` и так далее) для трёх схем; литералы цветов в `features/` запрещены правилом U21c.
- Высококонтрастная тема — третья схема в `cssVariablesResolver` плюс переопределения размеров компонентов (`Button`, `Input`, `Checkbox`, `Table`) по таблице выше.
