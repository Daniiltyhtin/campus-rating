# Campus Rating — C «Пульт» и D «Редакция»

Откройте [index.html](index.html) в браузере. Сборка и сервер не нужны. CSS, JavaScript, SVG и шаблоны находятся внутри файла; сеть нужна только для Google Fonts с кириллицей. Без сети работают системные запасные шрифты.

«Рядом», «Только C», «Только D» переключают показ, не перезагружая страницу. До 820 px варианты идут друг под другом. Телефоны имеют натуральную ширину 360 px; при достаточном месте соседние телефоны стоят рядом. Ниже — две таблицы преподавателя: минимальная ширина 1180 px, горизонтальная прокрутка только внутри рамки.

## Контраст и доступность

WCAG: канал sRGB `s = byte / 255`; линейный канал `s / 12.92` при `s ≤ 0.04045`, иначе `((s + 0.055) / 1.055)^2.4`. Яркость `L = 0.2126R + 0.7152G + 0.0722B`. Контраст `(Lmax + 0.05) / (Lmin + 0.05)`.

Скрипт `/tmp/check-tiles.cjs` читает вычисленные токены в Chromium и проверяет 32 пары на вариант: основной и вторичный текст на четырёх поверхностях, смысловые акценты на странице и карточке, кнопки, выбранные элементы, ошибки, успех и инверсное уведомление. Минимум **C — 6,92:1**, **D — 5,22:1**; в обоих случаях `--muted` на `--primary-soft`. Все проверенные пары выше 4,5:1. Границы и скелетоны не используются как цвет текста и не входят в текстовые пары. Шкалы дополнительных оттенков ниже — материал для темы, не разрешение использовать любой оттенок для текста на любом фоне.

Кнопки, поля, чекбоксы и пункты навигации имеют область нажатия не меньше 44 × 44 px. Видимый знак чекбокса — 18 px внутри области 44 px. Фокус виден; сегменты и фильтры работают мышью, клавиатурой и стрелками/Home/End. Поля связаны с подписями, ошибочный файл — с пояснением. Уведомления используют `role="status"`. При `prefers-reduced-motion: reduce` отключены все анимации и переходы, включая спиннер и скелетоны.

## Перенос в Mantine 9 / U21c

Это витрина выбора, тема приложения здесь не меняется. Параметры ниже ложатся в `createTheme`; `primaryColor` — имя шкалы в `colors`, `primaryShade` — её индекс. См. [Theme object](https://mantine.dev/theming/theme-object/) и [CSS variables](https://mantine.dev/styles/css-variables/).

| Настройка | C | D |
|---|---|---|
| `fontFamily` | `'IBM Plex Sans', sans-serif` | `'PT Sans', sans-serif` |
| `fontFamilyMonospace` | `'IBM Plex Mono', monospace` | Системный monospace для кода; суммы остаются PT Sans |
| `headings.fontFamily` | `'IBM Plex Sans', sans-serif` | `'Literata', Georgia, serif` |
| `headings.sizes` | h1 20/26 px, h2 16/21,6 px | h1 20/26 px, h2 16/21,6 px |
| `primaryColor` | `consoleLime` | `editorialWine` |
| `primaryShade` | 3 | 7 |
| `defaultRadius` | `2px` | `8px` |
| `shadows` | xs/sm/md/lg/xl: `none` | xs/sm/md/lg/xl: `3px 3px 0 #d4cabb` |
| Цветовая схема провайдера | dark | light |

Шкалы `colors`, ровно 10 оттенков от светлого к тёмному (индексы 0–9):

```js

  '#f8fce9', '#eef8c7', '#e3f5a1', '#d0ef78', '#b9db53',
  '#9bbd36', '#789529', '#596f20', '#3c5017', '#293812',
],
editorialWine: [
  '#fcf1f3', '#f6dfe5', '#edbdca', '#df95aa', '#cc6c88',
  '#b64c6c', '#9e3b56', '#862e43', '#6b2235', '#501a29',
],
```

В U21c хранить смысловые токены централизованно в `theme.other`, экспортировать через `cssVariablesResolver` в CSS-переменные темы: `--campus-status-overdue`, `--campus-status-progress`, `--campus-status-submitted`, `--campus-status-accepted`, `--campus-currency-ar`, `--campus-currency-bua`, `--campus-currency-boa`, а также поверхности, границы, ошибки и текст. Компоненты используют `var(--campus-…)`, без цветовых литералов. Таблица токенов выше — значения для выбранной темы.

Через общие настройки компонентов перенести высоту кнопок/полей 44 px, интервалы, рамки и оформление активного пункта. Основная кнопка C требует тёмного `--on-primary`, D — белого; задать это в общем resolver/styles кнопки вместе с hover/active, сохраняя проверенные пары. Для чисел — `font-variant-numeric: tabular-nums`; семейство чисел отдельным токеном. `respectReducedMotion: true` плюс общий CSS media query для собственных анимаций.

Шрифты приложения — локальные пакеты `@fontsource/ibm-plex-sans`, `@fontsource/ibm-plex-mono` либо `@fontsource/pt-sans`, `@fontsource/literata`, с кириллическими и латинскими начертаниями используемых весов. Google Fonts остаётся только в автономной витрине. Для PT Sans использовать реальные 400/700, для Literata 500/600/700, для Plex Sans 400/500/600/700, Plex Mono 400/500/600.

## Проверено

- Chromium через Playwright из `e2e/node_modules`: 1480, 1280 и 360 px; ошибок JavaScript и консоли нет, все четыре семейства шрифтов загрузились.
- На 360 px `document.documentElement.scrollWidth === 360`; все 12 телефонов шириной ровно 360 px, малых областей нажатия не найдено. На 1280/1480 ширина документа также равна окну.
- Переключение C/D/рядом, оба типа уведомлений, отключение анимации при reduced motion.
- Шаблоны фрагментов скопированы без изменения текстов и чисел; оба варианта клонируют их через `template.content.cloneNode(true)`.
- Скриншоты: `/tmp/campus-tiles-1480.png`, `/tmp/campus-tiles-1280.png`, `/tmp/campus-tiles-360.png`; отдельные крупные кадры `/tmp/tiles-task-c.png`, `/tmp/tiles-task-d.png`, `/tmp/tiles-desk-c.png`, `/tmp/tiles-desk-d.png`.

Витрина демонстрирует стили и локальные состояния: отправки на сервер, реальные переходы между экранами и пересчёт бюджета не реализованы. Проверка в других браузерах и на физических устройствах не проводилась. Файлы вариантов A/B не читались и не менялись.
