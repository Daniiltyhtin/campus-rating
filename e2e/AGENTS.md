# E2E — правила для агентов

Playwright против полного стека из `docker-compose.e2e.yml` (ускоренный штраф: интервал 4 с, poll-period 1 с). Дополняет корневой `AGENTS.md`.

## Сценарии

- Каждый тест соответствует сценарию из `docs/spec/test-plan.md`: стабильный ID, предусловия, шаги, ожидание, негативные ветки, источник (R/AE).
- Используются демо-аккаунты из сида; тест не зависит от данных, созданных другим тестом.
- Найденный баг сначала закрепляется тестом, потом исправляется.

## Как пользователь, а не как скрипт

- Локаторы — по ролям и подписям: `getByRole`, `getByLabel`, `getByText`. CSS-селекторы и `data-testid` — только когда иначе нельзя.
- Без `force: true` и кликов по скрытым элементам: если пользователь не видит кнопку, тест должен упасть.
- Ожидания — `expect.poll` и авто-ожидания Playwright, без `waitForTimeout`.
- Ключевые экраны — `toHaveScreenshot` на 360 и 1280 px.

## Нестабильность

- Нестабильный тест разбирается через trace viewer, а не лечится ретраями и увеличением таймаутов.
- Тесты штрафа ждут изменения АР опросом состояния с запасом в несколько интервалов.

## Команды

Появятся в мастер-U2: `docker compose -f docker-compose.yml -f docker-compose.e2e.yml up -d --build --wait`, затем `npm --prefix e2e test`.
